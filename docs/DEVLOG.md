## 1. 2026-08-06 · 小目标误检修复（本次优化）

### 1.1 问题现象

对测试图 `jpeg_dvp1_0_20240620164308.jpeg`（384×288）推理时：

- **期望**：用尽可能小的框包裹每个黄色小污点
- **实际**：模型输出**大蓝框误检**，覆盖图像大面积区域（173×173 像素，约 27% 面积），且置信度低（0.3 以下）；小黄点位置**完全没有检测框**

| 旧模型输出示例 | 尺寸 | 占比 | 判定 |
| --- | --- | --- | --- |
| `box=(211,0,384,173)` | 173×173 | 27.2% | ❌ 大框误检 |
| `box=(186,0,384,87)` | 198×87 | 15.5% | ❌ 大框误检 |

### 1.2 根因分析

**核心原因：训练用 `imgsz=640`，导致小目标特征丢失。**

1. 标注的小黄点归一化宽高仅 `0.006 ~ 0.02`，在 384×288 原图中约 **2~8 像素**
2. YOLOv8 骨干网络有 5 次下采样（步长 2），最终特征图分辨率 = `imgsz / 32`
3. `imgsz=640` 时最终特征图 `20×20`，小黄点经 5 次下采样后已不足 1 个特征点，**特征完全丢失**
4. 模型学不到小目标特征，只能退化为输出覆盖大范围的低置信度大框

```
小黄点 2~8 px ──(imgsz=640, 下采样 /32)──> 远小于 1 个特征像素 ❌ 特征丢失
小黄点 2~8 px ──(imgsz=1280, 下采样 /32)──> 保留更多特征像素 ✅ 可学习
```

### 1.3 优化方案

**方案A：先用推理参数探测（验证不可行）**

尝试提升推理 `imgsz`（640→1280→2048）和 `conf` 阈值，但**全部失败**——因为训练时模型就没学到小目标，推理端无论怎么放大都无效。这证明问题在训练端，必须重训。

**方案B：重新训练（最终方案）**

针对小目标全面调整训练配置，关键改动如下：

| 参数 | 旧值 | 新值 | 作用 |
| --- | --- | --- | --- |
| `imgsz` | 640 | **1280** | 保留小目标特征（核心修复） |
| `copy_paste` | 0.5 | **1.0** | 最强小目标增强，直接倍增小目标样本 |
| `mosaic` | 0.75 | **1.0** | 多图拼接，提升小目标上下文 |
| `mixup` | 0.2 | **0.3** | 增强泛化 |
| `fliplr/flipud` | 开 | **0.0** | 红外光伏板不需翻转 |
| `scale` | 0.5 | **0.1** | 小目标不能缩放太猛 |
| `single_cls` | 否 | **True** | 单类污点更稳定 |
| `close_mosaic` | 10 | **20** | 后20轮关闭 mosaic 稳定收敛 |
| 训练策略 | 直接训练 | **冻结骨干预热10轮 → 全量微调120轮** | 稳定小目标检测头 |

### 1.4 验证结果

**训练指标**（120 epoch，CPU，0.47 小时）：

| 指标 | 旧模型 | 新模型 |
| --- | --- | --- |
| Precision | 0.72 | **0.974** |
| Recall | 1.0 | **1.0** |
| mAP50 | 0.995 | **0.995** |
| mAP50-95 | 0.266 | **0.553** |

**推理结果**（对目标图 `jpeg_dvp1_0_20240620164308.jpeg`）：

| 输出 | 尺寸 | 置信度 | 判定 |
| --- | --- | --- | --- |
| `box=(165,72,171,79)` | 6×7 | 0.752 | ✅ 小框包裹黄点 |
| `box=(228,272,233,278)` | 6×6 | 0.690 | ✅ 小框包裹黄点 |

- 框中心 (167.5, 76.2) 与黄色小点质心**完全吻合**
- **大蓝框误检已完全消除**

### 1.5 代码固化

将验证最优的参数固化到 [YoloPV.py](../YoloPV.py)：

- **训练**：`mosaic=1.0 / mixup=0.3 / copy_paste=1.0 / close_mosaic=20 / 关闭翻转 / scale=0.1 / single_cls=True`
- **预测**：`iou` 默认 0.45 → **0.7**（小目标避免 NMS 合并框）
- 新增 `BEST_WEIGHTS` 常量，默认 predict/export 使用训练好的 [best.pt](../runs/detect/train/weights/best.pt)

```
# 复现本次优化后结果（两句命令）
python YoloPV.py train   --imgsz 1280 --epochs 120
python YoloPV.py predict --weights runs/detect/train/weights/best.pt
```

## 2. 优化前后对比

### 2.1 检测效果

| 阶段 | 检测框 | 是否包裹黄点 | 是否误检 |
| --- | --- | --- | --- |
| 优化前 | 大蓝框（~173×173） | ❌ 未包住 | ❌ 严重误检 |
| 优化后 | 小框（6×6 ~ 6×7） | ✅ 精准包裹 | ✅ 无误检 |

### 2.2 数据流影响

```
优化前：imgsz=640 训练 → 小目标特征丢失 → 大蓝框误检
优化后：imgsz=1280 训练 + copy_paste 增强 → 学到小目标 → 小框精检
```

## 3. 优化过程时间线

| 时间 | 动作 | 结果 |
| --- | --- | --- |
| 1. 定位现象 | 打印旧模型在目标图上的所有检测框 | 确认全为大蓝框误检，conf<0.3 |
| 2. 检查标注 | 读取 train 标签 txt | 确认小黄点归一化宽高 0.006~0.02（极小目标） |
| 3. 检查训练配置 | 读 args.yaml | 发现 `imgsz=640`，判为根因 |
| 4. 试探推理参数 | imgsz 640/1280/2048 × conf 多档 | 全部无法检出小目标，证明需重训 |
| 5. 阶段1训练 | 冻结骨干 10 epoch（imgsz=1280） | 完成，val mAP=0（头未充分学习，正常） |
| 6. 阶段2训练 | 全量微调 110 epoch | 完成，120 epoch 总耗时 0.47h |
| 7. 验证指标 | 读 results.csv | P=0.974 R=1.0 mAP50-95=0.553 |
| 8. 验证推理 | 新模型 predict + 黄点质心比对 | 检出 2 个 6×6/6×7 小框，框心与黄点吻合 |
| 9. 固化参数 | 更新 YoloPV.py 训练/推理默认值 | CLI 默认参数复现小框精检 |
